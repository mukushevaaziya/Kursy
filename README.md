# Учебный портал институтов

Статический сайт с курсами: Институт управления, Институт дипломатии, НШГП.
Темы слева, учебные страницы с отметкой «пройдено» и тесты с проверкой ответов.
Прогресс хранится в localStorage браузера.

Открыть: просто откройте `index.html` в браузере или включите GitHub Pages для ветки `main`.
